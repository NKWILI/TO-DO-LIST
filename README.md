
# ✅ To-Do List App

A simple and interactive **To-Do List** application built with **HTML**, **CSS**, and **JavaScript**. This app allows users to add, check off, and delete tasks — with automatic saving using **localStorage**.

## 🚀 Features

- ➕ Add new tasks  
- ✅ Mark tasks as completed  
- ❌ Delete tasks individually  
- 💾 Save tasks using `localStorage`  
- 🔄 Tasks persist after page refresh  
- 📱 Fully responsive layout

## 💡 How It Works

1. ✏️ User enters a task and clicks the **Add** button.  
2. 📃 Task is added to the list and displayed immediately.  
3. ✅ Clicking on a task toggles its **completed** status.  
4. ❌ Clicking the **×** button deletes the task.  
5. 💾 All tasks are saved in `localStorage`, so they remain after reloading the page.
